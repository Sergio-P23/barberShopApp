# 💈 BarberShop App

Aplicación móvil desarrollada con **Ionic** para la gestión y reserva de turnos en una barbería. 

> **Nota / Contexto del proyecto:** Este proyecto nació como una colaboración para apoyar a un colega en la creación del prototipo de la aplicación. Mi participación principal estuvo enfocada en el desarrollo del **Frontend** y en la **integración / consumo de APIs REST**. Fue un proyecto ligero y directo que sirvió para poner en práctica y afianzar conocimientos esenciales sobre el ecosistema Ionic.

---

## 🚀 Tecnologías y Herramientas

* **Ionic Framework** — Componentes de UI móviles e interfaz multiplataforma.
* **HTML5 / SCSS / TypeScript** — Estructura, estilos y lógica del cliente.
* **REST APIs / HttpClient** — Consumo e integración de servicios backend para el manejo de datos (reservas, catálogo de servicios, datos de usuario, etc.).

---

## ✨ Aportes y Aprendizajes

* **Desarrollo Frontend:** Implementación de vistas dinámicas y componentes de interfaz adaptados a dispositivos móviles.
* **Consumo de Servicios API:** Conexión con endpoints para lectura y envío de información de reservas en tiempo real.
* **Manejo de Ionic UI:** Experiencia práctica en maquetación rápida, navegación entre páginas y ciclo de vida de componentes Ionic.

---

## 📱 Funcionalidades Principales

- [x] Visualización de servicios y catálogo de la barbería.
- [x] Flujo de reserva de citas y selección de horarios.
- [x] Conexión e intercambio de datos con la API backend.
